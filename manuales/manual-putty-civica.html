1Instalar PuTTY en Linux

Desde una terminal, según tu distribución:

# Ubuntu / Debian / Mint
sudo apt update && sudo apt install -y putty putty-tools

# Fedora / RHEL
sudo dnf install -y putty

# Arch
sudo pacman -S putty

Esto instala PuTTY (la ventana gráfica, comando putty) y PuTTYgen (puttygen, conversor de llaves). También aparece en el menú de aplicaciones. Comprueba con putty --version (o ábrelo desde el menú).

2Guardar la llave privada

Del correo descarga las llaves. Estos son los archivos que recibiste:

ArchivoPara qué
private.ppkLa que se usa con PuTTY (pruébala primero).
private_2.ppk, private_3.ppk, private_4.ppkLlaves de respaldo: el correo indica que sirven para scp/otros clientes. Si private.ppk es rechazada, prueba una por una.
public.binLlave pública: no se usa para conectarte.

Guárdalas en una carpeta tuya con permisos restringidos:

mkdir -p ~/civica && chmod 700 ~/civica
mv ~/Descargas/private*.ppk ~/civica/
chmod 600 ~/civica/*.ppk
Las llaves son personales: no las compartas ni las subas a repositorios. Las contraseñas (de la llave y del usuario) no se guardan en archivos de texto sueltos; mejor un gestor de contraseñas. Llegan por mensajería interna, no por correo.

3Abrir PuTTY e indicar el servidor

Abre PuTTY. En la categoría Session (izquierda) escribe la dirección del servidor en Host Name (or IP address) y deja el puerto 22 con tipo de conexión SSH (recuadros rojos).

civica-1192.168.0.118

Las IP son de red interna (192.168.x.x): debes estar en la red de la oficina o conectado por VPN.

4Indicar tu usuario

En el árbol de la izquierda abre Connection › Data. En Auto-login username escribe tu usuario: geovani.rincon. Así PuTTY no te lo pide cada vez.

5Cargar la llave privada

Despliega Connection › SSH › Auth › Credentials. En Private key file for authentication pulsa Browse… y selecciona tu private.ppk.

6Guardar la sesión (para no repetir todo)

Vuelve a Session. En Saved Sessions escribe un nombre, por ejemplo civica-1, y pulsa Save. La próxima vez basta con hacer doble clic en ese nombre.

Repite los pasos 3 a 6 para civica-2 y civica-3 (cambia solo la IP y el nombre). Un atajo: carga civica-1, cambia la IP y guárdala con otro nombre.

7Conectar y aceptar la huella del servidor

Pulsa Open. La primera vez aparece una alerta de seguridad con la huella (fingerprint) del servidor. Es normal: pulsa Accept para guardarla. Si más adelante la alerta vuelve a salir con una huella distinta, cancela y avisa al equipo de infraestructura.

8Escribir la contraseña de la llave

Si ya guardaste el usuario, PuTTY mostrará Authenticating with public key … y pedirá Passphrase for key: escribe la contraseña de la llave privada que recibiste por mensajería interna y pulsa Enter.

Al escribirla no se ve nada (ni asteriscos). Es lo esperado.

9Listo: ya estás dentro

Verás el prompt geovani.rincon@civica-1:~$. Comprueba el servidor con hostname. Para usar permisos de administrador antepón sudo; ahí te pide la contraseña del usuario en el sistema operativo (la otra contraseña de la mensajería interna).

Si algo falla

MensajeQué hacer
Network error: Connection timed outNo hay ruta a la IP: conéctate a la VPN o a la red de la oficina y revisa la IP.
Unable to use key file … (OpenSSH SSH-2 private key)El archivo no es el correcto o está dañado. Selecciona private.ppk (o prueba private_2.ppk, private_3.ppk, private_4.ppk); public.bin no sirve.
Server refused our key / Access deniedRevisa que el usuario sea geovani.rincon (sin espacios ni mayúsculas) y que cargaste la llave en Auth › Credentials.
Wrong passphraseLa frase de la llave no coincide: vuelve a escribirla con cuidado (distingue mayúsculas).
Alerta de huella distinta a la que aceptasteNo continúes y avisa a infraestructura.
Sorry, try again en sudoEsa es la contraseña del usuario del sistema, no la de la llave.

Alternativa: ssh desde la terminal (sin ventana)

En Linux también puedes conectarte sin la interfaz gráfica. Como las llaves vienen en formato .ppk, conviértela a OpenSSH una sola vez:

puttygen ~/civica/private.ppk -O private-openssh -o ~/.ssh/civica
chmod 600 ~/.ssh/civica
ssh -i ~/.ssh/civica geovani.rincon@192.168.0.118

PuTTYgen pedirá la contraseña de la llave al convertir. Para copiar archivos: scp -i ~/.ssh/civica archivo geovani.rincon@192.168.0.118:~.

Para no escribir la IP, agrega a ~/.ssh/config:

Host civica-1
  HostName 192.168.0.118
  User geovani.rincon
  IdentityFile ~/.ssh/civica
# repite con civica-2 (.119) y civica-3 (.120)

Y conéctate con ssh civica-1.

Desde PuTTY también puedes abrir una sesión guardada por línea de comandos: putty -load civica-1.
